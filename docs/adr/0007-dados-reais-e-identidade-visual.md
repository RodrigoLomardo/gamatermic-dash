# ADR 0007 — Dados reais e identidade visual

Datasets derivados do relatório *Vendas Ploomes 2025_2026.xlsx* (abas Vendas, Propostas Ganhas/Perdidas/Abertas; ~10,4 mil linhas, jan/2025–out/2026). Chaves: `numero` (vendas); `codigo+revisao` (propostas). `propostas_abertas` usa `replace_snapshot`. A coluna calculada *Prazo de Pagamento* (fórmula de planilha) é lida pelo valor em cache (`data_only`). Campo `contato` marcado `pii` (mascarado para quem não tem `dataset:manage`). Widgets de propostas filtram `ultima_revisao = true` para não contar revisões antigas.
Identidade visual: **tokens oficiais** extraídos de gamatermic.com.br em 30/10/2026 — azul `#001F3B` (escuro `#001426`, médio `#00284d`, claro `#01498d`), laranja `#FF8A1E` (escuro `#CA6200`, claro `#F1A055`), cinza `#6C6C6C`, fundo claro `#F0F0F0`; fontes Public Sans (títulos) e Inter (corpo); logo oficial em `frontend/public/brand/logo-gamatermic.png`; botão primário com o canto superior direito quase reto, como no site. Dois ajustes por acessibilidade (AA): texto **azul-escuro** sobre o laranja (branco sobre `#FF8A1E` dá 2,3:1) e `--accent-dark` `#B25400` para texto laranja sobre fundo claro (o `#CA6200` do site dá 4:1). Tema TV de alto contraste em `[data-theme="tv"]`. Tokens em `frontend/src/styles.css`.
