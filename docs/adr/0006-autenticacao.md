# ADR 0006 — Autenticação e sessões

Access JWT HS256 de 10 min (`kid`, `iss`, `aud`, `typ=user|device`; algoritmo fixo na validação) em memória no frontend; permissões **não** vão no token (resolvidas no servidor, cache de 60 s invalidado por `authz_version`). Refresh opaco de 256 bits (só o hash no banco), cookie `HttpOnly; SameSite=Strict; Path=/api/v1/auth`, rotação a cada uso, tolerância de 10 s para abas concorrentes, reuso fora da janela revoga a família. CSRF: SameSite + conferência de `Origin` + header `X-Requested-With`. Senhas argon2id (política NIST: ≥12 caracteres, bloqueio de comuns), lockout 5 falhas → 15 min (progressivo), resposta de tempo similar para usuário inexistente. TVs: fluxo RFC 8628 adaptado, credencial opaca revogável + JWT `typ=device` de 15 min; token de dispositivo recebe 401 em qualquer rota de usuário (testado).
